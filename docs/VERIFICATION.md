# 本地包如何验收

验收数据由测试代码或随包虚构笔记生成。两条演示、核心和网关回归、公开 OB writer 兼容测试均可在安装依赖后离线运行；不需要生产账号或模型密钥。

- 包根目录执行 `python -m pytest -q`。主要断言覆盖计划跨记录结果／撤边、增量线索、双方向嵌入、活动分支、冷却、同一查询共享、补充线索、两种宿主生命周期与预算降级。网关默认在发给判断模型前复核来源；已撤回候选不会出现在判断请求，冲突可见性及未完成文本不进准备材料。
- 运行 README 的两个演示；观察确切引文、回执与后续轮次的直接回答。演示模型与向量使用固定替身，不代表任意外部供应商的命中表现或耗时。
- 按 OB 指南执行固定版本的 writer 测试：上游实际创建、编辑、归档合成桶，适配器读取当前可见内容。此验证不启动 OB 聊天前端。
- 用 `shasum -a 256 -c SHA256SUMS.txt` 核对解包完整性。构建时只纳入源码、文档、许可证、合成 Markdown 与实验补丁，无 Git 元数据和生产数据；生产的私人用例以合成文本替换。
