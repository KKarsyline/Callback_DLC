# 聊天应用的三个接入时点

[ChatHost](../host_example/coordination.py) 提供完整的进程内实现；已有网关的应用也可以按下表接线。

| 时点 | 宿主需要做什么 |
|---|---|
| 用户消息已保存 | 取当前会话和分支的可见历史，构造本轮作用域。保留原规划器、直接检索和直接回执。允许联想时，并行判断上一轮准备的候选；普通检索启动时，可以共享同一查询向量。对原始档案查询、主动消息、私密或已取消轮次，保留原聊天路径。 |
| 即将向回复模型提交请求 | 给可选联想留同一份等待预算。选到一件后，用原选择令牌调用 `final_admission`，复核当前授权和版本，只有通过才渲染额外的上下文。与直接命中重复、已撤回、超时或出错时，直接答案和原回执照常交付。 |
| 最终可见回复已落盘 | 用助手消息 ID 和最终文字核对实际提及，结算原令牌；未说出口就记为未使用。随后从当前分支重新读取刚完成的可见对话，准备下轮候选。取消或丢弃的回复不计提及。关闭服务时等待已提交的后台任务退出。 |

调用签名、分支存储约定和回执归属见[宿主接入指南](../host_example/README.md)。跨进程使用的四个方法见 [MCP 接线](mcp-lifespan.md)。
