# 独立实验：不会随核心启用

这里保留 11 月 19 日几种不同改动，便于复现实验。请在单独复制的代码和合成索引上比较，每个方案分别对照原版。

| 文件 | 改变什么 | 决定 |
|---|---|---|
| `evidence-cues.patch` | 写入提示优先描述可迁移的处境，再保留具体主题 | 手机定向对照两版均命中 1/4；未上线。 |
| `topic-and-relation.patch` | 不增加名额，在原提示中保留主题，并用一个槽位表达关系 | 未发现稳定提升；未上线。 |
| `query-first.patch` | 只改变后台对近期对话提出查询的方式 | 隔离回放对照项；未上线。 |
| `add_one.py` | 保持原查找方式，针对一件已确认漏找的事，核验后最多追加一条；保留旧线索和计划 | 备选，不做自动回填。额外成功的两次回放来自同一事件。 |

在独立副本的包根目录执行 `git apply --check experiments/topic-and-relation.patch` 可先验证补丁是否匹配。两个写入提示补丁针对同一原版，不叠加。定点补写可通过 `python -m pytest -q tests/test_experimental_add.py` 在临时数据库试验。真实索引、可定位个人的查询、运行记录和一次性生产运维脚本未收录。
