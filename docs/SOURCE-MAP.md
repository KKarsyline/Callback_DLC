# 实现与来源对照

**随包的两个数据边界。** 默认先重验原文，再让外部小模型看到有效短名单；两项工作与宿主原规划器重叠进行。线上原有的同起并发仍保留：只有当本地判断器与源库属于同一信任边界、允许处理轮间缓存引文、且不会转发到外部时，才给 `GatewayJudge` 设置 `trusted_cache_judge=True`。切换策略可能改变短名单能否赶上本轮，额外等待上限不增加。可见对话根据顶层和嵌套的可见性、完成标志筛选；回填也预先剔除已作废原始事件。这些是移植包的默认策略，生产部署未作改动。

第一期接通线索索引、轮间预备与当轮选择。第二期加入独立搜索方向、可核验的计划结果和按对话回合计算的冷却。后续的最终证据核对、计划刷新与授权读取行为见[修复与验证](FRESHNESS.md)。

| 本包位置 | 来自何处、保留什么 |
|---|---|
| `assoc_index.py` | 新增的线索生成、双重核验、版本绑定、合法归档、检索与增量预热。移植时把原文行窗口绑定到宿主已授权的最新正文，不按片段提供的文件路径再次打开文件。 |
| `assoc_plans.py`、`assoc_recall.py`、`assoc_budget.py` | 本轮新增原模块：状态与跨记录后续复核；准备、验证、现场查询、选择令牌和落盘；记忆服务预算。 |
| `pipeline/associative_recall.py`、`pipeline/association_scheduler.py`、`pipeline/assoc_budget.py` | 本轮新增网关模块：短名单缓存、并行验证和判断、分支与时限、渲染、实际提及及改述核验。移植时从宿主取预算 DB 路径，并中性化一句面向模型的表述。 |
| `embedding_engine.py` | 从嵌入引擎新增改动中提取双方向批量、返回位置核验、共享查询任务、短时缓存、已有向量读取及路由选项；构造器与客户端绑定独立编写。没有打包原宿主完整的嵌入引擎。 |
| `storage/turn_store.py`、`callback_ids.py` | 本轮新增的活动分支 SQL 查询；直接检索兼容旧片段 ID 和“所属桶 ID:16 位小写十六进制”片段 ID 的可移植校验。保留宿主已有的整批接收和回执逻辑。 |
| `reference/`、`service.py`、`backfill.py`、`host_example/` | 原宿主 MCP、聊天钩子的新增行与两份原回填脚本作为迁移参考。新的本地服务入口、通用回填和宿主示例把这些功能接到用户自己的存储和聊天循环。原脚本依赖原应用环境；独立包使用根目录的回填入口。 |
| `adapters/ombre_brain/`、`providers.py`、`memory_edges.py`、`self_anchor.py`、`source_refs.py`、`pipeline/memory_gateway_planner.py` | 本次打包编写的宿主接口：授权与可见性、来源窗口、关系、可见对话投影、模型连接。没有复制旧宿主的整体实现。 |
| `tests/` | 原专项测试加上移植回归、合成聊天和接口检查；对几个带历史影子的样例替换文本，修正原测试的 mock 清理。独立宿主还有 OB 读写兼容测试。 |

**范围。** 旧宿主使用过 Haven-Ombre；早期直接检索另有第三方候选池。这一包保留两期新写的模块，从既有文件中仅提取本轮的行为或新增钩子，没有带走旧宿主、旧候选池或第三方源码树。公开许可只覆盖本包内可授权的内容。不包含生产配置、模型凭据、笔记库、SQLite 内容、向量、日志、截图或对话回放。
